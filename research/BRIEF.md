# 研究ブリーフ

## テーマ
複数のAIエージェントセッション（Claude Code のクラウドセッション等）が、人間の監督なしに長時間（一晩）自律的に共同研究するための設計パターン

## 問い
1. 役割分担: 何人で、どんな役割に分けると成果の質が上がるか（同質並列 vs 役割分化、批判役の効果など）
2. 同期・共有: エージェント間で知見を共有する方法（共有ファイル/掲示板/メッセージ）と、衝突・重複作業の防ぎ方
3. 品質管理: 幻覚・根拠の薄い主張・堂々巡りをどう検出し抑えるか
4. コスト: 使用量（トークン）あたりの成果を最大化する運用（サイクル間隔、打ち切り条件など）
5. 結論: この `research/` の仕組み（PROTOCOL.md）を次回どう改善すべきか、具体的な提案

## 情報源
Web 上の論文（multi-agent LLM, debate, AutoGen, CAMEL, ChatDev, MetaGPT, AI Scientist 等）、公式ドキュメント、実践記事。
主張には必ず出典URLを付けること。出典のない推測は「推測」と明記。
