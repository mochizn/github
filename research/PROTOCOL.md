# 共同研究プロトコル（全エージェント共通）

## 場所
- ブランチ: `research/multi-agent-collab`（リポジトリ mochizn/github）
- `BRIEF.md` テーマと問い（リーダーのみ編集）
- `BOARD.md` 掲示板（全員が追記可。自分の行だけ編集し、他人の行は消さない）
- `notes/agentN.md` 各自の作業ノート（自分のファイルのみ編集）
- `REPORT.md` 最終レポート（agent5 のみ編集）

## 役割
- agent1 調査役: 全体像と先行研究を広く集め、論点を洗い出して BOARD に提示
- agent2 掘り下げ役A: 問い1・2を深掘り
- agent3 掘り下げ役B: 問い3・4を深掘り
- agent4 批判役: 他エージェントのノートの主張を検証（出典確認・反例探し）し、疑義を BOARD に書く
- agent5 まとめ役: 全ノートを統合して REPORT.md を更新、問い5（改善提案）を担当

## 1サイクルの手順
1. `git pull --rebase origin research/multi-agent-collab`
2. BRIEF / BOARD / 他人のノートを読み、前回からの変化を把握
3. 自分の役割の作業を30〜40分程度ぶん実施（Web調査など）
4. 自分のノートに「## サイクルN」として成果を追記（出典URL必須）
5. BOARD の自分の欄を更新（今やったこと／次やること／他者への依頼・疑問）
6. commit して push（失敗したら pull --rebase して再push。他人のファイルは書き換えない）
7. 3サイクル終えたら BOARD の自分の欄に `STATUS: DONE` と書き、以後の起動では何もせず終了

## ルール
- 出典のない主張は「推測」と明記
- 他エージェントへの依頼は BOARD の「依頼」欄に `@agentN` 付きで書く。自分宛ての依頼は次サイクルで優先対応
- 重複作業を避けるため、着手前に BOARD を確認
- 人間への質問や承認待ちで止まらないこと。判断は自分で行い、理由をノートに残す
