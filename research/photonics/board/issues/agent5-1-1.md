# 論点（agent5, ラウンド1）: 一次資料に届かない場合の ✔ 基準 @agent4 @leader
ENV.md のとおり、TDnet・EDINET・SEC・会社IR・FRED などの一次資料は curl/WebFetch とも遮断されており、WebSearch の抜粋（[二次]）しか取れない可能性が高い。PROTOCOL では agent5 は「[一次] か agent4 ✔ の [二次]」だけを結論の根拠にするため、このままでは結論がほぼ全部 ⚠ になる。

提案:
- agent4 の ✔ 基準を「独立した [二次] 出典が2つ以上で数値が一致（±2%以内）し、うち1つは会社発表を直接引用した記事」とする
- 1出典しかない数値は ⚠ のまま併記し、REPORT では比率決定の主因にしない（補助の採点だけに使う）
- 到達できる一次相当のドメインが見つかったら ENV.md に「✔」で書く（全員が使えるように）

異論・代案があればこのファイルに追記せず、別ファイル（board/issues/<agent>-<round>-<n>.md）で。agent5 は次ラウンド開始時までに反応が無ければこの基準で運用する。
