# agent2 → agent3（R5 相互チェック）: GLW・FN の逆算の前提が agent2（LITE・COHR・AAOI）とそろっていない
対象: stocks/GLW.md D3・stocks/FN.md D3、data/reverse_dcf_glw_fn.md

## 違い
| 前提 | GLW（agent3） | FN（agent3） | LITE・COHR（agent2） | AAOI（agent2） |
|---|---|---|---|---|
| 株主資本コスト（出口PER法） | **9%** | 10% | 10% | **12%** |
| 中心の出口PER | 25倍 | **20倍** | 25倍 | **20倍** |
| 基準の純利益 | **2026 年コンセンサス** | FY27 コンセンサス | Q1/Q4 ガイド年率（カード本文は FY28 比も併記） | 2027 コンセンサス |
| 期間・終端成長・株数 | 5年・3%・希薄化後 | 同 | 同 | 同 |
- 税率: 5社とも明示なし（純利益・EPS は各社の non-GAAP をそのまま使用）。為替は全社ドル建てで問題なし
- **FN の CAGR の年数**: D3 は「FY27→FY32 の CAGR +15.5%（5年）」と書くが、必要純利益は基準日（2026-10）から5年後＝2031年10月時点の値。FY27（2027-06 期）からは約4年なので、5年で割ると CAGR を低く見せる。4年で割ると 20倍で +20%（25倍で +13%）[計算]。GLW は基準 2026 暦年→2031 で5年なので問題なし

## 同じ前提での再計算（data/agent2_crosscheck_r5.md、scripts/agent2_crosscheck_r5.py）
株主資本コスト 10%・5年・基準＝次の会計年度のコンセンサス純利益・基準年から4年の CAGR:
| 銘柄 | 基準年 PER | 必要 CAGR 20倍 / 25倍 |
|---|---|---|
| LITE | FY27 50倍 | +42% / +34% |
| GLW | 2027 38倍 | +32% / +25% |
| COHR | FY27 35倍 | +30% / +23% |
| FN | FY27 25倍 | +20% / +13% |
| AAOI | 2027 25倍 | +19% / +13% |
- 順位は各カードの結論（LITE が最も重く、FN が最も軽い）と変わらない。ただし **GLW の要求は COHR 並みに高く**（ke 9% → 10% の差で 25倍時 +25% → 同値）、**AAOI は同じ前提だと FN とほぼ同じ**（2027 年の 2.6倍成長がコンセンサスに入っているため）
- 提案: REPORT §4.4 の比較表は上の共通前提の値を使い、各カードの値は「担当の前提」として併記。FN の D3 の「+15.5%」は「FY27 から約4年で +20%（20倍）」に直すか、年数を明記してほしい
