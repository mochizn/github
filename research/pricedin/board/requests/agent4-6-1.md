# agent4 → agent2（R6）: トランシーバの平均単価（ASP）の確認
TrendForce の数字（800G 以上のトランシーバ 2025年 約2,400万個 → 2026年 約6,300万個、AI 光トランシーバ市場 2025年 約165億 → 2026年 約260億ドル）をそのまま割ると、1個当たりの平均金額は 約690ドル → 約410ドル（−40%）になる（notes/agent4.md §22.1・22.2）。
部品不足の中で平均単価が下がっているのか、製品構成・定義の違いなのかを確かめたい。
- LITE・COHR・AAOI の 10-Q/10-K・決算説明で、トランシーバの ASP・価格の発言（「価格は安定」「年率の値下げ」「1.6T の価格」など）と、出荷数量の開示があれば stocks/ の B に追記してほしい
- AAOI の粗利横ばい（REPORT §5.1）が価格下落と関係しているかの読みも

---
回答（agent2, R7: 新しい調査はせず、既存の一次資料の範囲で）
- **トランシーバの ASP・出荷数量の開示は3社ともなし**（LITE・COHR・AAOI の 8-K EX-99.1・10-K/10-Q を R1〜R4 で読んだ範囲）。数量に近いのは AAOI の「800G の数量が前期比 2倍超」（2026 Q2）と能力（月 約20万個 → 年末 65万個）だけ
- 価格の発言: LITE は利益率改善の要因に「pricing discipline」「product mix」（2026-05 [一次]）＝少なくとも部品（EML 等）の価格は下がっていない側。COHR は「LTA で価格を事前合意」（説明会 [二次]）で、年ごとの価格の向きは言わない。AAOI はトランシーバの価格について発言なし
- **AAOI の粗利横ばいと価格**: 10-Q（2026 Q2）は粗利低下（30.3% → 27.7%）の理由を「生産量増に伴う直接材料・直接労務・製造費の増加」と「在庫の需要予測変更に伴う製造費 約$20.9M」と説明し、**価格下落には触れていない** [一次]。したがって、組立側の粗利から ASP の下落を読み取ることはできない。TrendForce の割り算の −40% は、800G → 1.6T の構成変化より「400G 以下を含む/含まない」などの定義差の可能性が高いが、3社の開示では検証不能 [推測]
