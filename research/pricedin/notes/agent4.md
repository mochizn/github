# agent4 ノート（業界横断・セクター要因）

## 最新の要点（R6, 2026-10-06）
- **供給能力表（§20）**: 均衡の時期は部材で違う。モジュール組立は均衡済み → コネクタ 2027年 → EML・InP・SiPh・ファイバ 2027年後半〜2028年。過剰のリスクは EML が最も早く（2028年後半〜）、ファイバが最も遅い（2029〜31年、フジクラの大型増強は 2029年度〜2030年）。EML は業界の見方自体が「2026年末に解消」（LightCounting）〜「2027年も不足」（TrendForce・LITE）に割れている
- **CPO/LPO シナリオ（§21）**: 速いケース（CPO 35%・LPO 25%）でプラガブル −17.5%、DSP −42%、レーザー個数 −13%、ファイバ +3.5%。不利は AAOI（大）・COHR（中）、有利は GLW・精工技研・FN（CPO 組立）。市場は CPO を置き換えと見ておらず、6/9 に最も不利な AAOI・COHR が最も下げた
- **設備投資の価格/数量（§22）**: 2026年の増加（+76%）の約55〜60%はメモリ中心の価格。数量は +30%前後で、NVIDIA の DC 売上 +89%・GPU 単価 +35〜50% と整合。**光の比率は総額では低下したが、メモリ以外に対しては 4.0% → 4.9% に上昇**（REPORT §0.2 #12 は格下げを提案）。新たな注意点: TrendForce の数字ではトランシーバの平均単価が −40%（agent2 に確認依頼 agent4-6-1）
- **§5.6（§23）**: 中国勢の予想PER は約24倍で米国勢の約半分（規制による締め出しの織り込み）。耐用年数は Amazon だけ短縮（10-K 一次）。U2 は確認不能（コンセンサスの内訳が有料）
- 時期の一覧は §24（agent5 の「時間のずれ」の章へ）。R4 は §13〜§19、R3 は §12、R1 は §1〜§9

## R1 の要点
- **設備投資ガイダンスは1年で一方向に上方修正**（一次: 各社 8-K）。米4社の2026年ガイダンス合計は約7,475億ドル（MSFT 暦年 約1,900億は二次）、2025年実績の約1.8倍。ただし **2026年4月以降の上方修正の主因は「部品（メモリ）価格の上昇」と会社自身が説明**（META 4/29 一次、AMZN 7/30・MSFT 4/29 二次）＝金額の増加が光の数量の増加を意味しない
- **資金の出どころが変わった**（一次）: Alphabet が 2026年6月に株式等で 496億ドル調達＋400億ドル ATM、Oracle は 200億ドル ATM 完了・FY26 FCF −237億ドル、Amazon の TTM FCF は −76億ドル。設備投資の上限は「キャッシュフロー」から「資本市場」に移った
- **セクター要因の分解**（data/agent4_factor.md）: 1年の上昇の大部分は半導体全体（SMH/日経）へのβで説明できる。指標と光セクターを除いた**個別要因が大きくプラスなのは LITE（対数 +1.16）と精工技研（+0.61）だけ**。FN（−0.70）・GLW（−0.22）は個別要因がマイナス
- **光株が一斉に反応したイベント**（data/agent4_events.csv）: プラス＝NVIDIA の出資（3/2 +12%）、Corning-Meta 契約（1/27 +9.5%）、AMZN の 2026年 2,000億ドル（2/6 +11%）、META/MSFT 決算（7/30 +12%）。マイナス＝AVGO 決算（2025/12/12 −11%）、SemiAnalysis の CPO 遅延報道（6/9 −10%）、NVDA 決算（2025/11/20・2026/2/26 各 −7%）
- 次ラウンド: agent5 依頼（agent5-1-4）の残り（2027年コンセンサスの推移、市場規模、能力増強表、CPO 時期、規制の現状、電力）。各銘柄担当は §5 の表で「その日は業界要因か」を確認できる

- **U-a（上振れ）1.6T の供給不足が 2027年も続く**なら、価格の下落（年8〜15%が通常）が 2027年も起きず、利益率のピークが延びる

### 13.3 計算: メモリを除いた設備投資の伸び [推測: 二次の比率を当てた試算]

### 14.1 部品不足の終わり方の読み [推測]
1. **InP は 2027年末に「COHR の自力解消」と「LITE の不足継続」が分かれる**。COHR は 2025年末比で約4倍超（2倍×2倍超）、LITE は前年比 +50% のペースで新工場は 2028年。業界の不足（LITE のいう 30% 超）が 2027年中に COHR の増強で埋まる可能性がある。**LITE が不足の期間を言わない（§5.2 #3）のは、競合の増強で 2027〜28年に需給が緩む可能性があるため**とも読める

- **いつ表に出るか**: COHR の 10〜11月の決算（6インチ InP の立ち上がり、EML の外販の有無）、LITE の 11月の決算（EML の価格・リードタイム）、TrendForce の EML 価格

### 21.4 スケールアップの光化（表の外の上振れ）
- NVLink（GPU 同士）を光でつなぐと、1ラック当たりのリンク数がスケールアウトの数倍になる（前回研究の「GPU 1基当たり光 1:3 → 1:4.5〜8」）。LightCounting はスケールアップの LPO/CPO の大量導入を **2028年**、2028〜30年に市場を再び二桁成長に戻すと見る [二次]（§15.1）
- この需要は CPO・LPO（モジュール型でないもの）で入る可能性が高いので、**勝者は CW レーザー（ELS）・ファイバ・コネクタ・FAU、敗者は DSP 付きプラガブル**。スケールアウトの CPO より影響が大きい
- REPORT §5.6 の U2（スケールアップの光化がコンセンサスに入っているか）: コンセンサスの予想期間（FY28 前後まで）の外で、**株価の要求（§12.1、2030年まで年+40%）は暗にこれを含んでいる**と読む [推測]。U2 は「株価には部分的に織り込み、コンセンサスには未反映」

### 21.5 織り込みの判定
- 6/9（CPO 2028〜29年説）の値動き: AAOI −17%・COHR −11%・LITE −8%・GLW −7%・FN −6%、精工技研 −13%・住友電工 −12%・フジクラ −7%（§5）。**S3 で最も不利な AAOI・COHR が最も下げた** → 市場は CPO を「置き換え」ではなく「AI 光の需要全体のアクセル」と見ている（R4 の判定を維持）
- 逆に言えば、CPO が予定どおり来ても AAOI・COHR の株価がプラスに反応し続けるなら、S3 の数量効果（モジュール −17.5%）は**未織り込み**
- いつ表に出るか: NVIDIA の Rubin 世代の CPO スイッチの出荷量（2026年度後半〜2027年の NVIDIA 決算）、2027年3月の GTC・OFC、COHR・AAOI の 1.6T の顧客構成

- **結論 [推測]**: 2026年の設備投資の増加（+76%）の**半分強（約55〜60%）は価格（主にメモリ）**、数量の伸びは +30% 前後。2027年は HBM4 の価格が2倍超になる見通しで、価格の比重はさらに上がりうる（§13.3 のメモリ以外 +15% 前後と整合）

- **新しい注意点（⚠ 要確認）**: TrendForce の数字どおりなら、トランシーバ1個当たりの平均金額は 2025年 約690ドル → 2026年 約410ドル（**−40%**）。製品構成（800G の比重）の変化か、価格の下落か、定義の違い（数量と金額の対象範囲）かは不明。**部品不足の中で平均単価が下がっているなら、不足が解けた後の価格の下落はさらに大きい可能性**。agent2 の LITE・COHR の ASP の発言で確かめたい（board へ依頼）
- REPORT §0.2 #12（光 ÷ 設備投資の低下）の**修正**: 総額に対する比率は下がった（3.6% → 3.3%）が、**メモリ以外の設備投資に対する比率は 約4.0% → 約4.9% に上がった**。比率の低下はメモリ価格の膨張によるもので、光の需要が弱いことを意味しない。#12 は「下振れ」より「設備投資の金額で光を見ると誤る」という注意点に格下げを提案
